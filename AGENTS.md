# PAT — Project Assessment Toolkit

Keep changes concise and proportional to the demonstrated need. Prefer the shared
assessment service to parallel implementations or speculative framework layers.

Assessments inspect source and supplied evidence without executing the assessed
project, loading its plugins, contacting its services, or changing its files.
Keep source snapshots, judgments, and goals separate. Preserve evidence identity,
versioned rubrics, access boundaries, and concurrent-update checks.

Source-supported burden estimates are useful when clearly labeled and cited.
Counts alone never establish burden; justified security or injection boundaries
can still impose upkeep. Preserve unknowns where evidence is genuinely missing.

Use Python 3.11+ with the src layout. Keep default tests offline. Validate changes
with pytest and Ruff; exercise the local browser and MCP adapters when changed.
Do not add deployment or paid CI workflows without an explicit request.
